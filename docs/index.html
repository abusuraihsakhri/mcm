The gap

Retrieval finds relevant text. Editing also needs structural consequence.

MCM does not discard semantic search. It places search on top of a canonical representation that knows what symbols are, how they relate, what evidence supports each relation and when that fact was valid.

01 · FIND

Semantic retrieval

Useful when the agent knows what something does but not where it lives or what it is called.

“where are tokens validated?”
02 · CONNECT

Explicit relations

Calls, tests, imports and inheritance are represented directly instead of being inferred from textual similarity.

Signer.sign → Serializer.dumps
03 · PREDICT

Pre-action change impact

Once the target is resolved, the graph can be traversed before the edit to surface downstream code and relevant tests.

How it works

A proposed edit becomes an evidence-backed context package.

The important difference is that change analysis starts before the agent writes. MCM resolves the symbol, traverses structural relations, preserves evidence and then passes the bounded result to the agent.

01

Ingest

Parse the repository into stable code objects and typed relations.

02

Resolve

Map the task or proposed edit to a concrete symbol identity.

03

Traverse

Follow relevant dependencies and decay confidence along the path.

04

Ground

Keep the source bytes and provenance that support each surfaced relation.

05

Package

Return only the context required for the next agent action.

Evidence

The current results are promising in places, mixed overall, and explicit about the null.

The repository now separates retrieval/context efficiency, impact prediction, and downstream agent performance. They are different experiments and should not be collapsed into one headline claim.

10repositories in the complete feature-hashing suite
6ecosystems across four repository-size tiers
0.88impact precision over five repositories at 7% firing rate
0.28agent-study paired sign-flip p-value

Context efficiency has a real signal

In the complete feature-hashing sweep MCM is ahead of vector RAG on 7/10 repositories and level on 3/10. Against the hybrid baseline it is ahead on 7/10 and level on 3/10.

It is not universal

requests is a counterexample in both sweeps, and python-dotenv falls behind the best baseline with the trained embedding. The architecture should not be presented as uniformly superior.

Embedding choice materially changes the comparison

The default feature hashing is not a trained sentence model. The trained-embedding sweep improves the vector baseline and weakens the original graph > vector-rag hypothesis.

The agent benefit is not demonstrated

The separate agent experiment cannot show that giving the agent mcm_impact improves file selection. The apparent subgroup improvement does not survive the usage check.

p = 0.2823 paired task deltas

Agent-in-the-loop: current result is a null

Across 23 tasks and three trials per condition there were 138 trials, six errored. Treatment was better on 5 tasks, worse on 2 and tied on 16; the mean paired delta was +0.072. A two-sided sign-flip permutation test gives p = 0.28.

Only 9/23 tasks were downstream consequences of the target—the problem propagation is intended to predict. Eleven were upstream co-requirements and three had no recorded edge.

Integrate

Use the same model from the CLI or directly inside a coding agent.

The default indexer and hashed embedding provider run locally. The MCP server uses stdio, so supported coding agents can query MCM without a separate network service.

Index a repository

git clone https://github.com/abusuraihsakhri/mcm.git
cd mcm
python -m venv .venv
pip install -e ".[dev,api]"

mcm ingest /path/to/repo --db mcm.db
mcm index --db mcm.db

Current measurements report roughly 66 files/s; Django’s 2,932 Python files index in about 44 seconds on the test laptop.

Formal core

The mathematics describes what must survive compression and traversal.

The site keeps the formal layer concise: canonical knowledge, confidence on composed relations, and support-preserving context reduction.

Canonical store

Objects, relations, evidence, provenance and temporal validity are primary; indexes are rebuildable projections.

K = ⟨ O, R, E, P, T ⟩

Path confidence

Longer or weaker relation chains carry less certainty than direct structural observations.

c(R₁ ∘ R₂) = c(R₁)c(R₂)δ(R₁,R₂)

Context entailment

A reduced package is accepted only if it preserves relevant closure, referenced objects and live evidence.

C* = arg min |C| subject to C ⊨ Q

What is implemented now

Python parsing, canonical store, hybrid retrieval, dependency reasoning, pre-action impact, context minimisation, MCP/REST surfaces, benchmark tooling and runtime/test observation channels.

What still bounds the claim

Python-only extraction, one horizon per evaluation repository, feature hashing as the default embedding, fitted-weight overfitting, and no demonstrated agent-performance gain in the current experiment.
