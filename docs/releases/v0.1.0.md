# Mathematical Context Model (MCM) v0.1.0

MCM v0.1.0 is the first citable research release of the Mathematical Context Model, a research prototype for semantic code memory, repository retrieval, dependency analysis, and pre-action change-impact analysis for coding agents.

## What is included

- Typed repository objects and relations with evidence and provenance.
- Temporal validity tracking for repository facts.
- Hybrid retrieval combining graph structure, lexical retrieval, vector similarity, symbolic resolution, and provenance.
- Pre-action change-impact analysis with typed change propagation and per-hop confidence.
- Context minimisation with consistency and evidence checks.
- Local CLI, REST API, and MCP stdio server interfaces.
- A reproducible benchmark framework using held-out Git history.
- An interactive static documentation portal.

## Evaluation summary

The evaluation is designed to test, rather than assume, the central claims of the architecture.

Hyperparameters are fitted on `httpx` and held out from the scored repositories. Retrieval is evaluated against future changes drawn from Git history, under matched context budgets and independently implemented baselines.

Across the reported `itsdangerous`, `flask`, and `django` evaluations, MCM shows stronger retrieval performance than the tested vector-RAG, graph-memory, and hybrid-RRF baselines on the reported recall, precision, and MRR results. The originally specified ordering `MCM > Graph > Vector RAG` is not supported: graph memory does not consistently outperform vector RAG.

The agent-in-the-loop experiment is also negative: providing MCM impact analysis did not significantly change which files the agent edited in the reported 23-task experiment (`p = 0.28`). This release preserves that null result rather than treating implementation correctness as evidence of downstream agent benefit.

See `docs/evaluation.md` for the full protocol, numerical results, uncertainty estimates, tuning procedure, and threats to validity.

## Scope and limitations

This release should be treated as a research prototype, not as a production-ready or state-of-the-art claim.

Important limitations include:

- Python-only static parsing and extraction.
- Incomplete visibility into dynamic dispatch and runtime-only relationships unless observation channels are used.
- A limited number of evaluated repositories and historical horizons.
- Dependence of some comparative results on the embedding provider.
- A token estimator that is not a model-specific BPE tokenizer.
- Limited agent-in-the-loop evidence, with no demonstrated downstream task-completion improvement in the current experiment.

## Reproducibility

The repository includes the implementation, tests, benchmark code, evaluation documentation, and experiment artifacts required to inspect the reported methodology.

Typical local setup:

```bash
git clone https://github.com/abusuraihsakhri/mcm.git
cd mcm
python -m venv .venv
# Windows:
.venv/Scripts/activate
# macOS/Linux:
# source .venv/bin/activate
pip install -e ".[dev,api]"
pytest
```
